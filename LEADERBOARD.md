# Records

Les records affichés dans le menu et sur la page des scores proviennent du stockage local du navigateur. Le jeu conserve le meilleur score enregistré pour chaque pseudo sur l’appareil.

La sauvegarde Google Drive permet de retrouver le score lié à son point de reprise sur un autre appareil. Consulte le [guide de sauvegarde](SAVE_SYSTEM.md).

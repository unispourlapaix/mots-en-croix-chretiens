# Sauvegarde du jeu

Le navigateur conserve les grilles et les records sur l’appareil.

Dans **Menu → Profil**, la connexion Google donne accès à un espace privé de l’application sur Google Drive. **Sauvegarder** y enregistre le pseudo et un point de reprise avec le mode, le niveau et les scores. **Reprendre la sauvegarde** permet de retrouver ce point sur un autre appareil avec le même compte Google.

La [configuration Google Drive](README.md#connexion-et-sauvegarde) est nécessaire pour utiliser la sauvegarde en ligne.
